Три Notebook находятся в корне репозитория (локально — в code/). Каждый соответствует одной лекции и содержит оглавление с переходами к разделам. Нумерация и порядок разделов совпадают со слайдами.
Основной язык текста — русский. Комментарии в коде написаны на русском и китайском.

Запуск
Установка среды и запуск Jupyter описаны в разделе 1.1 первой лекции. Команды терминала показаны в Markdown; их следует выполнять в Anaconda Prompt.
Запустите jupyter notebook, откройте Notebook нужной лекции, выберите ядро Python 3 и выполняйте ячейки сверху вниз.
Для первых двух лекций нужны NumPy и Matplotlib. Для третьей дополнительно нужен PyTorch: в терминале среды курса выполните python -m pip install torch.

Модели и воспроизводимость
Перенос в плёнке: трёхмерная изотропная серая модель фононов из слайдов.
PINN: уравнение теплопроводности с гауссовым начальным профилем температуры.
Результаты случайного моделирования и обучения могут меняться с версиями библиотек и порядком вызовов генератора случайных чисел.
